# 🎣 摸鱼时刻 · 在线钓鱼小游戏

适合上班摸鱼的多人在线钓鱼小游戏。输入名字即可开钓，第一视角湖面，
鱼上钩后鱼竿抖动、点击收杆，按鱼的**稀有度**划分难度（越稀有，收杆窗口越短）。
右侧实时显示在线玩家列表与渔获排行榜。

## 特点

- **零依赖**：只用 Node.js 自带模块，手写 WebSocket，不用 `npm install`。
- **一条命令启动**：服务器同时托管前端页面和实时联机。
- **真·多人联机**：不同电脑的同事能实时看到彼此的在线状态和渔获。
- **服务器裁判**：钓到什么鱼、是否成功都由服务器随机决定并校验，前端改不了。

## 运行

需要本机装有 Node.js（建议 16+）。

```bash
node server.js
```

然后浏览器打开 http://localhost:3000

自定义端口：

```bash
PORT=8080 node server.js        # macOS/Linux
set PORT=8080 && node server.js # Windows CMD
$env:PORT=8080; node server.js  # Windows PowerShell
```

## 让同事访问

1. **同一局域网**：同事直接访问 `http://<你的内网IP>:3000`。
2. **内网穿透**（跨网络）：用 frp / ngrok / cpolar 等把 3000 端口映射到公网。
   - ngrok 示例：`ngrok http 3000`，把生成的网址发给同事即可。
   - 通过 https 域名访问时，前端会自动用 `wss://` 连接，无需改代码。

## 玩法

1. 输入名字 → 开始钓鱼。
2. 点「抛竿」，浮漂入水，静等鱼咬钩（1.5~5.5 秒随机）。
3. 鱼上钩时鱼竿剧烈抖动、按钮变「收杆」，**在时间窗口内点击收杆**才算钓到。
4. 品质越高，收杆窗口越短（红·传说只有 0.6 秒），手慢就脱钩。
5. 钓到金/红品质会播放特殊检视动画，并全场广播喜报。

### 品质与鱼种

六档品质，由低到高（颜色越靠后越罕见、收杆窗口越短）：

| 品质 | 颜色 | 收杆窗口 | 代表鱼种 |
|------|------|---------|---------|
| 白·杂物 | ⚪ 白 | 2.6s | 破靴子、海草、空易拉罐、小贝壳 |
| 绿·普通 | 🟢 绿 | 2.2s | 小白条、鲫鱼、小河虾、泥鳅 |
| 蓝·精良 | 🔵 蓝 | 1.8s | 鲤鱼、鲶鱼、大闸蟹 |
| 紫·稀有 | 🟣 紫 | 1.3s | 鲈鱼、老甲鱼、墨鱼 |
| 金·史诗 | 🟡 金 | 0.9s | 河豚、黄金鱼、黄金章鱼 |
| 红·传说 | 🔴 红 | 0.6s | 彩色锦鲤、锦鲤之王、深海鲸王（1000 分）|

- 共 20 种，钓到**金/红**品质时会播放全屏特殊检视动画并全场广播喜报。
- 点左上角「📖 图鉴」可查看全部鱼种与个人收集进度（已捕获点亮、未捕获显示问号，按名字存在浏览器本地）。

鱼种出现概率、分值在 `server.js` 顶部的 `FISH_TABLE` 中调整。

## 项目结构

```
server.js          零依赖后端：静态服务 + 手写 WebSocket + 钓鱼裁判
public/
  index.html       登录页 + 游戏场景 + 在线面板的结构
  style.css        纯 CSS 第一视角湖面、鱼竿抖动等动画
  game.js          前端状态机、WebSocket 通信、列表渲染
```
